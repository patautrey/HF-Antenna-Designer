What This Antenna Is

The Hex Beam is a lightweight, compact directional HF antenna that uses six fiberglass spreaders to support a pair of wire elements shaped into a broad hexagon. It offers beam-like performance with lower wind load and easier installation compared to traditional Yagi antennas.

How This Antenna Is Modeled

  • Reflector spacing determines front-to-back ratio.
  • Driven element perimeter sets resonant frequency.
  • Spreader length defines the hexagonal geometry.
  • Mutual coupling between wires shapes the radiation pattern.
  • Height above ground influences takeoff angle and gain.
