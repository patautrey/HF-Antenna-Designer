# Flowerpot Coaxial (T2LT) — Documentation

## Overview
The Flowerpot (T2LT) antenna is a coaxial sleeve vertical using the inner conductor as the radiator and the outer braid as the sleeve. It requires a 1:1 choke at the feedpoint and does not use radials.

## Modules
- Flowerpot Coaxial (main calculator)
- Diagram generator
- Build sheet
- Multiband designer
- Performance analyzer
- Field planner
- Height optimizer
- Coax loss calculator

## Construction Notes
- Radiator and sleeve are each approximately 1/4 wavelength.
- A choke is required at the feedpoint.
- Sleeve and radiator lengths may require trimming.
- PVC support mast is optional.
