HF Workbench – Quick Start

1. First-Time Setup

  1. Open HF Workbench in a modern desktop browser.
  2. Verify the top navigation bar is visible.
  3. If the interface looks outdated, use Ctrl+F5 to refresh.

2. Basic Workflow

2.1 Choose a Tool

  1. Select Doublet, Loop, Skyloop, or a tool under Verticals ▼.
  2. The tool loads into the main content area.

2.2 Enter Parameters

  • Choose your band or frequency.
  • Enter lengths (total, leg, or loop perimeter).
  • Enter height and radial details if applicable.

2.3 Review Results

  • Check band coverage and pattern hints.
  • Adjust geometry and re-evaluate.

3. Tool Selection Guide

  • Doublet: One wire, many bands.
  • Loop: Compact or noise-reducing designs.
  • Skyloop: Large multi-band loop.
  • Vertical DX: Low-angle DX performance.
  • Vertical NVIS: Regional high-angle coverage.
  • Performer Vertical: Optimize a single vertical.
  • Dominator Array: Multi-element directional arrays.
