HF Workbench – User Manual

1. Introduction

HF Workbench is a browser-based suite of antenna design tools for HF operators. It provides fast, practical modeling guidance without requiring NEC software, installation, or complex configuration. Each tool focuses on real-world operator needs: band coverage, height effects, feedline behavior, and expected performance.

This manual covers the layout, shared concepts, and each tool in detail: Doublet, Loop, Skyloop, Vertical DX Designer, Vertical NVIS Designer, Performer Vertical, and Dominator Array.

2. Navigation and Layout

2.1 Top Navigation Bar

The navigation bar provides access to all tools:

  • Home – Returns to the welcome screen.
  • Doublet – Multi-band center-fed wire designer.
  • Loop – Small/medium loop designer.
  • Skyloop – Large horizontal loop designer.
  • Verticals ▼ – Dropdown containing:
    • Vertical DX Designer
    • Vertical NVIS Designer
    • Performer Vertical
    • Dominator Array
  • Help ▼ – User Manual, Quick Start, Glossary.

2.2 Main Content Area

When you select a tool, HF Workbench loads the module into the main content area without reloading the entire page. This keeps navigation fast and responsive.

Tip: If the interface looks outdated after an update, use Ctrl+F5 to clear cached scripts.

3. Shared Concepts

3.1 Frequency and Bands

  • Design Frequency: The primary band used for calculations.
  • Multi-band Behavior: Many tools show how a geometry behaves across HF bands.

3.2 Geometry

  • Total Length: Overall wire length.
  • Leg Length: For center-fed antennas.
  • Height: Average or maximum height above ground.
  • Shape: Straight, loop, skyloop, or vertical.

3.3 Feedline and Matching

  • Feedpoint Impedance: Modeled impedance at the feedpoint.
  • Feedline Type: Coax, ladder line, etc.
  • Matching: Tuner or matching network expectations.

3.4 Performance Indicators

  • Takeoff Angle: Low = DX, High = NVIS.
  • Efficiency: Radiated vs. lost power.
  • Pattern Hints: Lobes, nulls, and directional tendencies.

4. Tool Reference

4.1 Doublet Designer

The Doublet Designer helps plan multi-band center-fed wire antennas using balanced feedline and a tuner. Ideal for 80–10m coverage.

Inputs

  • Primary band
  • Total length or leg length
  • Height
  • Feedline type

Outputs

  • Impedance by band
  • Pattern tendencies
  • Tuner difficulty estimates

4.2 Loop Designer

For small/medium loops used in limited spaces or for noise reduction.

Inputs

  • Circumference
  • Shape
  • Height
  • Band

Outputs

  • Radiation resistance
  • Efficiency hints
  • Pattern notes

4.3 Skyloop Designer

For large horizontal loops used for multi-band coverage with a tuner.

Inputs

  • Perimeter
  • Height
  • Target bands

Outputs

  • Band-by-band behavior
  • NVIS vs. DX tendencies
  • Lobe structure at higher bands

4.4 Vertical DX Designer

For low-angle verticals optimized for long-distance DX.

Inputs

  • Vertical height
  • Radial system
  • Ground type
  • Band

Outputs

  • Takeoff angle
  • Efficiency hints
  • Pattern notes

4.5 Vertical NVIS Designer

For verticals optimized for regional NVIS coverage.

Inputs

  • Height
  • Loading options
  • Band

Outputs

  • High-angle radiation
  • NVIS effectiveness
  • Tradeoffs vs. DX

4.6 Performer Vertical

For maximizing performance from a single vertical in limited space.

Inputs

  • Height
  • Radial count
  • Band goals

Outputs

  • Efficiency/bandwidth tradeoffs
  • Incremental improvement suggestions

4.7 Dominator Array

For exploring multi-element vertical arrays with directional gain.

Inputs

  • Element count
  • Spacing
  • Phasing
  • Band

Outputs

  • Forward gain expectations
  • Front-to-back behavior
  • Complexity vs. benefit

5. Example Workflows

5.1 80m Doublet for Multi-Band Use

  1. Open Doublet.
  2. Set band to 80m.
  3. Enter ~135 ft total length.
  4. Set height.
  5. Review multi-band behavior.

5.2 Backyard Skyloop

  1. Open Skyloop.
  2. Enter perimeter.
  3. Enter height.
  4. Review band coverage.

5.3 40m DX Vertical

  1. Open Vertical DX Designer.
  2. Enter height.
  3. Enter radial system.
  4. Review takeoff angle.

6. Best Practices

  • Start simple.
  • Document your choices.
  • Iterate before cutting wire.
  • Validate with real QSOs and RBN.
