HF Workbench – User Manual

1. Introduction

HF Workbench is a browser-based collection of antenna design tools focused on practical HF operation. It is designed for operators who want to explore “what if” scenarios, plan new antennas, and understand how geometry, height, and band choice affect performance.

This manual describes the overall layout, common concepts, and each tool in the suite: Doublet, Loop, Skyloop, Vertical DX Designer, Vertical NVIS Designer, Performer Vertical, and Dominator Array.

2. Layout and Navigation

2.1 Top Navigation Bar

The top navigation bar provides access to all tools and help pages:

  • Home – Returns to the HF Workbench welcome screen.
  • Doublet – Opens the Doublet Designer module.
  • Loop – Opens the Loop Designer module.
  • Skyloop – Opens the Skyloop Designer module.
  • Verticals ▼ – Dropdown with:
    • Vertical DX Designer
    • Vertical NVIS Designer
    • Performer Vertical
    • Dominator Array
  • Help ▼ – Dropdown with:
    • User Manual (this page)
    • Quick Start
    • Glossary

2.2 Main Content Area

The main content area is where each tool’s interface appears. When you click a tool in the navigation bar, HF Workbench loads that module into the content area without reloading the entire site.

Tip: If the interface looks “stuck” or outdated after a code change, use a hard refresh (Ctrl+F5 or equivalent) to clear cached scripts.

3. Common Concepts Across Tools

3.1 Frequency and Bands

  • Design Frequency: The primary frequency or band used for calculations.
  • Multi-band Behavior: Many tools show how a single geometry behaves across multiple HF bands.

3.2 Geometry and Dimensions

  • Total Length: Overall wire length (e.g., total doublet length or loop perimeter).
  • Leg Length: Length of each side of a center-fed antenna.
  • Height: Average or maximum height above ground.
  • Shape: Straight wire, loop, skyloop, or vertical arrangement.

3.3 Feedline and Matching

  • Feedpoint Impedance: Modeled impedance at the antenna feedpoint.
  • Feedline Type: Coax, ladder line, or other transmission line.
  • Matching Network: Tuner or matching system used to achieve a good match at the rig.

3.4 Performance Indicators

  • Takeoff Angle: Elevation angle where most energy is radiated.
  • Efficiency: How much power is radiated vs. lost as heat.
  • Pattern Hints: Qualitative notes about lobes, nulls, and coverage.

4. Tool Reference

4.1 Doublet Designer

The Doublet Designer is for planning multi-band center-fed wire antennas, typically used with balanced feedline and a tuner. It is ideal for 80–10m coverage from a single wire.

Inputs

  • Primary band (e.g., 80m, 40m).
  • Total length or leg length.
  • Average height above ground.
  • Feedline type (ladder line, coax, etc.).

Outputs

  • Approximate feedpoint impedance by band.
  • Qualitative pattern behavior (NVIS vs. DX tendencies).
  • Guidance on tuner expectations and likely “easy” vs “difficult” bands.
Use case: “I want one wire that covers many bands with a tuner and ladder line.”

4.2 Loop Designer

The Loop Designer focuses on small or medium-sized loops, often used where space is limited or where noise rejection is important.

Inputs

  • Loop circumference (total wire length).
  • Loop shape (square, rectangle, etc.).
  • Height above ground.
  • Operating band or frequency.

Outputs

  • Approximate radiation resistance and efficiency hints.
  • Pattern notes (broadside vs. edgewise, null directions).
  • Guidance on tuning and matching expectations.

4.3 Skyloop Designer

The Skyloop Designer is for large horizontal loops (often full-wave or larger on 80m or 40m), typically used for multi-band coverage with a tuner.

Inputs

  • Perimeter (total loop length you can fit in your space).
  • Average height above ground.
  • Target bands (e.g., 80–10m).

Outputs

  • Band-by-band behavior (where it is near-resonant, where it is not).
  • NVIS vs. DX tendencies by band.
  • Qualitative pattern hints (number and direction of lobes at higher bands).

4.4 Vertical DX Designer

The Vertical DX Designer helps configure vertical antennas aimed at low-angle radiation for long-distance (DX) contacts.

Inputs

  • Vertical height (physical radiator length).
  • Radial system details (number, length, and type of radials).
  • Ground type (good, average, poor).
  • Target band(s) (e.g., 40m, 20m).

Outputs

  • Estimated takeoff angle for DX.
  • Efficiency hints based on radial system and ground.
  • Pattern notes (omnidirectional vs. slight directional bias).

4.5 Vertical NVIS Designer

The Vertical NVIS Designer focuses on vertical configurations optimized for near-vertical incidence skywave (NVIS) coverage—short to medium HF distances.

Inputs

  • Vertical height and any top-loading or loading coils.
  • Target NVIS bands (often 80m and 40m).
  • Ground and radial configuration.

Outputs

  • Higher-angle radiation emphasis for regional coverage.
  • Guidance on height vs. NVIS effectiveness.
  • Tradeoffs between NVIS and DX performance.

4.6 Performer Vertical

The Performer Vertical tool is oriented toward squeezing performance out of a single vertical within real-world constraints (yard size, support height, radial count).

Inputs

  • Available vertical height.
  • Number and length of radials you can practically install.
  • Primary band(s) of interest.

Outputs

  • Efficiency and bandwidth tradeoff guidance.
  • Suggestions for incremental improvements (more radials, slightly taller, etc.).
  • Qualitative expectations for on-air performance.

4.7 Dominator Array

The Dominator Array tool explores multi-element vertical arrays for pattern control (gain and directivity).

Inputs

  • Number of elements.
  • Element spacing and layout.
  • Phasing or feeding scheme.
  • Target band.

Outputs

  • Qualitative forward gain expectations.
  • Front-to-back or front-to-side behavior.
  • Notes on complexity vs. benefit.

5. Example Workflows

5.1 Planning an 80m Doublet for Multi-Band Use

  1. Open Doublet from the top navigation.
  2. Set the primary band to 80m.
  3. Enter a total length around 130–140 feet.
  4. Set the average height (e.g., 35 feet).
  5. Choose ladder line as the feedline type.
  6. Review the behavior on 80m, 40m, 20m, and higher bands.

5.2 Sketching a Backyard Skyloop

  1. Open Skyloop.
  2. Measure your available perimeter (e.g., fence line) and enter that as the loop length.
  3. Set the average height based on your supports.
  4. Review which bands the loop is near-resonant on and how it behaves on others.

5.3 Building a 40m DX Vertical

  1. Open Verticals ▼ → Vertical DX Designer.
  2. Enter your available vertical height (e.g., 33 feet).
  3. Specify your radial system (e.g., 16 radials at 0.25λ each).
  4. Set the target band to 40m.
  5. Review the estimated takeoff angle and efficiency hints.

6. Tips and Best Practices

  • Start simple: Begin with a single-band design, then expand to multi-band.
  • Document your choices: Keep notes on lengths, heights, and feedline decisions.
  • Iterate: Use HF Workbench to explore multiple options before cutting wire.
  • Validate on air: Use real QSOs, RBN spots, and reports to confirm performance.
