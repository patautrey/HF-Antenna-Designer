HF Workbench – User Manual

1. Overview

HF Workbench is a collection of web-based tools for designing and exploring HF antennas. It runs entirely in your browser—no installation required—and focuses on practical, “operator-first” design workflows.

The current tool set includes:

  • Doublet Designer – General-purpose multi-band doublet planning.
  • Loop Designer – Small loop / magnetic loop style designs.
  • Skyloop Designer – Large horizontal loop / skyloop planning.
  • Vertical DX Designer – Ground-mounted or elevated verticals for DX.
  • Vertical NVIS Designer – Low-angle verticals optimized for NVIS coverage.
  • Performer Vertical – Performance-focused vertical configuration tool.
  • Dominator Array – Multi-element vertical array exploration.
Note: HF Workbench is a design aid, not a replacement for on-air testing. Always verify modeled performance with real-world measurements where possible.

3. Common Concepts

Several concepts appear across multiple tools. Understanding these will make the individual designers easier to use.

3.1 Frequency and Bands

  • Design Frequency – The primary frequency (or band) the tool uses for calculations.
  • Multi-band Behavior – Some tools show how a given geometry behaves on multiple HF bands.

3.2 Wire Lengths and Geometry

  • Total Length – Overall wire length of the antenna (e.g., total doublet length).
  • Leg Length – Length of each side of a center-fed antenna.
  • Height – Average or maximum height above ground.
  • Shape – Straight, loop, skyloop, or multi-element vertical arrangements.

3.3 Feedline and Matching

  • Feedpoint Impedance – The modeled impedance at the antenna feedpoint.
  • Feedline Type – Coax, ladder line, or other transmission line types.
  • Matching Network – External tuner or matching system used to achieve a good match at the rig.

4. Tool Reference

4.1 Doublet Designer

The Doublet Designer helps you plan a multi-band center-fed wire antenna. It is especially useful for 80–10m coverage using a tuner and balanced feedline.

  • Inputs: desired bands, total length, height, feedline type.
  • Outputs: approximate impedance by band, pattern hints, and tuning expectations.

4.2 Loop Designer

The Loop Designer focuses on small or medium-sized loops, often used where space is limited or where noise rejection is important.

  • Inputs: loop circumference, shape, height, frequency.
  • Outputs: approximate radiation resistance, efficiency hints, and pattern notes.

4.3 Skyloop Designer

The Skyloop Designer is for large horizontal loops (often full-wave or larger on 80m or 40m), typically used for all-band coverage with a tuner.

  • Inputs: perimeter, average height, band coverage goals.
  • Outputs: band-by-band behavior, likely lobes, and NVIS vs DX tendencies.

4.4 Vertical DX Designer

The Vertical DX Designer helps you configure vertical antennas aimed at low-angle radiation for long-distance (DX) contacts.

  • Inputs: vertical height, radial system details, ground type, target band(s).
  • Outputs: estimated takeoff angle, efficiency hints, and pattern notes.

4.5 Vertical NVIS Designer

The Vertical NVIS Designer focuses on vertical configurations optimized for near-vertical incidence skywave (NVIS) coverage—short to medium HF distances.

  • Inputs: height, loading options, band selection.
  • Outputs: higher-angle radiation emphasis and coverage expectations.

4.6 Performer Vertical

The Performer Vertical tool is oriented toward squeezing performance out of a single vertical within practical constraints (yard size, support height, radial count).

  • Inputs: available height, radial count/length, band goals.
  • Outputs: tradeoff guidance between efficiency, bandwidth, and complexity.

4.7 Dominator Array

The Dominator Array tool explores multi-element vertical arrays for pattern control (gain and directivity).

  • Inputs: number of elements, spacing, phasing, band.
  • Outputs: qualitative pattern behavior (forward gain, F/B expectations).

5. Workflow Tips

  • Start simple: Begin with a single-band design, then expand to multi-band.
  • Document your choices: Keep notes on lengths, heights, and feedline choices.
  • Iterate: Use the tools to explore “what if” scenarios before cutting wire.
  • Validate on air: Use real QSOs, RBN spots, and reports to confirm performance.
